Outputs

Generated Output Files

  • report.html → self-contained interactive HTML report. All results (cohort table, per-sample histograms, indices, interruption variants) are embedded directly in the file at generation time; there is nothing to upload or select, just open it in a browser.

  • Final_report.xlsx → consolidated Excel report including definitive allele peaks, CCG counts per allele, instability/expansion indices, LOI/DOI flags, and resolved warnings. This is the primary spreadsheet output; use this one, not report_0.xlsx.

  • raw_counts/ → per-sample CSV files with raw read-level counts and annotations (CAG, CCG, LOI/DOI, sequence). Not needed to view report.html (its histograms are pre-computed and embedded), but useful for custom downstream analysis, and required if you later run Index_Calculation mode on this output folder.

  • report_0.xlsx → an intermediate, draft Excel report written before CCG assignment and warning resolution. It is not the deliverable; it exists mainly for debugging and is superseded by Final_report.xlsx.

If --cag_graph or --ccg_graph are enabled, additional subdirectories are created:

  • CAG_graphs/, CCG_alleles_graphs/ → per-sample histograms.

  • warning_case/, forced_graphs/ → outputs for warning samples and their forced resolution.

Warning samples and forced resolution If a sample shows a non-canonical histogram (e.g., unclear or noisy peaks), STRmie-HD flags it as warning.

  • By default, the tool retries a forced peak search (forced_graphs/), applying a broader scan for candidate peaks.

  • If the --cwt option is enabled, STRmie-HD additionally applies wavelet-based peak detection (scipy.signal.find_peaks_cwt) to test multiple alternative strategies and recover allele peaks in ambiguous cases.

All forced or re-analyzed cases are saved in:

  • warning_case/ → plots and data for flagged samples.

  • forced_graphs/ → results from the forced peak search.

HTML report Step by Step workflow

report.html is self-contained: open it directly in a browser after a Complete Pipeline run, no upload step required.

1) Cohort overview The report opens on a searchable, sortable table with one row per sample: genotype (CAG1/CAG2), a clinical category badge (Normal / Intermediate / Reduced penetrance / Full penetrance / Needs review), Instability Index, Expansion Index, Allele Ratio, and interruption-variant flags (LOI-CAA, LOI-CCA, DOI shown when above 10%).

2) Per-sample detail view Click any row to open its detail panel: CAG and CCG repeat-length histograms (called allele peaks highlighted), the full metric set with a plain-language interpretation next to each value, and a bar view of the LOI-CAA/LOI-CCA/DOI percentages.

3) Glossary Click the ? button in the header to open a glossary panel defining every metric shown in the report (Instability Index, Expansion Index, Allele Ratio, LOI_CAA, LOI_CCA, DOI, CCG alleles, Max_CAG_observed, warning/needs-review samples, and the Index_Calculation workflow below).

Generate a table for recalculating indices (Index_Calculation mode)

This mode is designed for cases where automatic allele calling requires manual refinement. From a sample's detail view, use "Add to manual review list" to add it to the correction table at the bottom of the report; the CAG allele fields are pre-filled with the currently detected values, so you only need to edit the ones that are wrong.

How to proceed

  1. Inspect the histogram and the reported allele peaks in the sample's detail view.

  2. If the automatic peaks do not match the histogram, click "Add to manual review list".

  3. In the Manual allele correction table, edit CAG_Allele_1 / CAG_Allele_2 for that sample.

  4. Click Export corrected alleles (.xlsx) to download CAG_data_for_recalculating_indices.xlsx.

  5. Recompute indices with the corrected alleles:

strmie --mode Index_Calculation -o tests/example_file/strmie_output/ -p /path/to/CAG_data_for_recalculating_indices.xlsx

Parameters

  • -o /path/to/output_dir/ → must be the same output folder specified when running the Complete Pipeline (this mode reads the raw_counts/ subfolder created there). -f/--input is not used in this mode.

  • -p /path/to/CAG_data_for_recalculating_indices.xlsx → the Excel file you exported from the report.

Biological considerations for manual correction

  • If there is no reference peak for the healthy allele, or mosaicism shows two peaks for the expanded allele and none for the healthy one, a reasonable default range for the healthy allele (Allele 1) is 10–26 CAG repeats; for the expanded allele, the most expanded peak visible in the histogram is generally the appropriate choice.

  • In rare cases where automatic peak detection fails entirely (a sample flagged "Needs review"), supply both allele values manually based on the peaks visible in the histogram.

Outcome

  • Index_Calculation recomputes II and EI using the corrected allele peaks, aligning metrics with visual evidence from histograms.
