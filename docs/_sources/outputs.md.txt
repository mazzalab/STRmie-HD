# Outputs and manual review

## HTT complete-pipeline files

| File or directory | Contents and conditions |
|---|---|
| `Final_report.xlsx` | Main spreadsheet: called CAG alleles, CCG assignments, II/EI, Allele Ratio, interruption percentages and maximum observed CAG |
| `report.html` | Cohort table, per-sample histograms, glossary and manual-correction table; result data embedded |
| `raw_counts/<sample>.csv` | Matched reads retained after CAG filtering; required for index recalculation |
| `CAG_CCG_histograms.xlsx` | Tidy histograms with `Sample`, `Repeat_Type`, `Repeat_Length`, `Read_Count` |
| `report_0.xlsx` | Intermediate report before CCG assignment and fallback processing |
| `forced search.xlsx` | Written only when CAG warning cases trigger a retry |
| `pear_merge_stats.xlsx` | Merge percentages when PEAR processes pairs, including automatically extracted BAM/CRAM pairs |
| `paired_end_merged/` | Merged gzip FASTQs and other PEAR outputs when merging occurs |
| `extracted_fastq/` | FASTQs from BAM/CRAM extraction |
| `CAG_graphs/` | JPEG CAG plots if `--cag_graph` is enabled |
| `CCG_alleles_graphs/`, `warning_case/`, `forced_graphs/` | CCG plots and applicable warning/retry plots if `--ccg_graph` is enabled; directories may be empty |

The `raw_counts` name does not mean every input read is retained. Nonmatching reads and those removed by `-m` are absent. Its columns are `ID`, `CAG_repeats`, `CCG_repeats`, `LOI_CAA`, `LOI_CCA`, `Seq`, `DOI`, `filename`.

The histogram workbook pools CCG counts across all retained reads per sample. The optional CCG allele plots use reads around each called CAG peak. Those distributions have different selection rules.

## Main spreadsheet columns

| Column | Meaning |
|---|---|
| `Sample` | Resolved input basename, including sequence-file extension |
| `CAG_repeatsPeak_Allele_1`, `CAG_repeatsPeak_Allele_2` | Ordered CAG peak calls; a sole accepted peak is repeated |
| `CCG_allele_1`, `CCG_allele_2` | Most frequent CCG count among reads at that CAG peak, widening to ±1 then ±2 units only when needed |
| `Instability_Index` | Signed rank-weighted index around the longer called allele |
| `Expansion_Index` | Rank-weighted signal at/above the longer allele, normalized to its peak height |
| `Allele_Ratio` | Read signal above `-c` divided by signal at/below it, rounded to two decimals |
| `LOI_CAA`, `LOI_CCA`, `DOI` | Percentages of retained reads with each parser annotation, on a 0–100 scale |
| `Max_CAG_observed` | Largest retained read-level CAG count; not an independently called allele |

The name `Final_report.xlsx` identifies the pipeline's final spreadsheet, not a guarantee that every call is resolved. Inspect strings such as `warning` or `It cannot be calculated`, empty values and atypical distributions.

## Explore the HTML report

Open `report.html` in a browser. There is no upload/import step for the workbook or raw-count folder: the report contains its own summary data and histograms. It loads **Plotly 2.35.2** and **SheetJS 0.18.5** from external CDNs, so it is not fully offline. If scripts are blocked, charts or the Excel export may fail even though the table is visible.

1. Search or sort the cohort table.
2. Click a sample row to open the detail panel with CAG and CCG histograms, metrics and interruption percentages.
3. Use the **Glossary and help** button in the report header to open the glossary.
4. Compare peak calls with the observed distributions before selecting samples for manual review.

The report classifies the longer called CAG peak using fixed software boundaries: ≤26 `Normal`, 27–35 `Intermediate`, 36–39 `Reduced penetrance`, and ≥40 `Full penetrance`; nonnumeric calls become `Needs review`. These display boundaries do not change with `-c`. They are distinct from Allele Ratio's default split at 27.

LOI/DOI badges appear when a percentage is **strictly greater than 10%**. This is a display threshold, separate from `-ti` and `-te`, and not a read-filtering or validated positivity threshold.

The old documentation screenshots showed uploading an Excel file and selecting a raw-count folder. Those screenshots have been removed because that interface is no longer generated by the supplied code.

## Manual allele review and recalculation

1. Open the sample detail panel and choose **+ Add to manual review list**.
2. In **Manual allele correction**, edit the prefilled CAG allele values using the observed data and any independent evidence available for that sample.
3. Select **Export corrected alleles (.xlsx)**. The browser downloads `CAG_data_for_recalculating_indices.xlsx` containing `Sample`, `CAG_Allele_1`, `CAG_Allele_2`.
4. Export before closing or reloading the page; edits are held in the page's memory.
5. Recalculate using the original output directory and the same analysis thresholds:

```bash
strmie --mode Index_Calculation   -o /path/to/original_output   -p /path/to/CAG_data_for_recalculating_indices.xlsx
```

`indices_calculation.xlsx` includes only the listed samples, with recalculated indices, ratio, interruption percentages and maximum CAG. It writes an additional spreadsheet index column. It **does not update the original report, HTML, histograms or CCG assignments**. For supported corrected peaks, the retained reads, LOI/DOI percentages and maximum observed count remain based on the same input data.
