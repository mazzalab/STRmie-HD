# Input file types

STRmie-HD supports both **short-read** (Illumina) and **long-read** (PacBio HiFi/CCS, Oxford Nanopore) sequencing platforms.

By default, STRmie-HD relies on **exact regular-expression matching** to identify repeat tracts and interruption motifs, which performs best on high-accuracy data (Illumina, PacBio HiFi/CCS). Oxford Nanopore's higher per-read error rate can break an exact match; use the `--nanopore` flag to switch to a fuzzy, edit-distance-tolerant matching mode instead (see [Operational Modes](operational-modes.html)).

STRmie-HD accepts as input:
- **fastq.gz** → gzipped file of raw reads with base calls and quality scores.
- **fasta.gz** → gzipped file of sequences without quality scores.
- **BAM** (`--bam`) / **CRAM** (`--cram`, requires `--reference`) → indexed, aligned reads. STRmie-HD extracts the reads relevant to the target locus internally and converts them to FASTQ before analysis, so no separate export step is needed even for large whole-genome files.

> 💡 *Tip*: Merging is especially useful for repeat-rich regions (e.g., *HTT*), where overlap-aware merging improves accuracy by using base qualities and positional evidence.
