# STRmie-HD

**Short Tandem Repeat Mapping and Identification Engine – Huntington's Disease**

STRmie-HD counts repeat tracts in sequencing reads and supports review of HTT CAG/CCG allele calls, interruption patterns and somatic instability indices. It produces Excel tables and an interactive HTML report. The separate `strmie-repeat` command applies catalog-defined repeat matching to FMR1, C9orf72 or a custom locus.

This documentation describes the supplied source snapshot. Package metadata still reports `0.1.0`; this is not a claim that every packaged distribution contains the same features.
